# Milestones

> **Scope:** Milestone definitions and review gates  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Milestones should be visible checkpoints where the portfolio can be reviewed independently. Each one should correspond to a working demo slice and a clear acceptance gate.

## 2. Milestone Definitions

### M1: Foundation Ready
- Monorepo, CI, Docker Compose, frontend shell, API gateway, auth, and rate limiting are working.

### M2: Core AI Ready
- Chatbot RAG, vector search, and face recognition are available through the UI.

### M3: Realtime Ready
- Metrics dashboard, live logs, and API explorer show live data and working contracts.

### M4: Advanced AI Ready
- Multi-agent orchestration, AI playground, and workflow automation are functional.

### M5: Production Ready
- Security, admin controls, performance, and deployment checks are complete.

## 3. Review Checklist

- Demo must be interactive and not merely static screenshots.
- Acceptance criteria for the phase must be verifiable.
- Known gaps and follow-up work must be documented.

## 4. Sign-Off Criteria

- Core routes and modules are accessible.
- Critical bugs are resolved or explicitly tracked.
- The next phase can begin without blocking dependencies.
