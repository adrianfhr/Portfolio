# API Explorer — Animations

> **Module:** API Explorer  
> **Version:** 1.0

## 1. Overview

Animations should help the explorer feel responsive without distracting from the API details.

## 2. Key Animations

### 2.1 Sidebar Transition
- Sidebar can slide or fade into place on smaller screens.

### 2.2 Request Execution
- Use a short loading state while the request is running.

### 2.3 Response Reveal
- Render the response with a quick fade-in or highlight.

### 2.4 Auth State
- Successful authorization can trigger a subtle confirmation transition.

## 3. Reduced Motion

- Respect reduced-motion preferences.
- Keep the docs usable without decorative transitions.
