# Prompt Library

> **Scope:** Reusable prompt patterns and templates  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

The prompt library stores repeatable prompt patterns that can be reused across demos and internal workflows. It should focus on clarity, traceability, and safe composition.

## 2. Template Principles

- Keep system instructions separate from user content.
- Use clear delimiters between instructions and task data.
- Avoid hidden behavior inside prompt text.

## 3. Example Prompt Types

- RAG assistant prompt.
- Code review helper prompt.
- Creative writing or ideation prompt.
- Socratic teaching prompt.

## 4. Versioning

- Version prompt templates alongside the modules that use them.
- Keep change notes when prompt behavior materially changes.
