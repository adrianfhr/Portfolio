# Observability Layout

> **Scope:** Dashboard and monitoring page structure  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Observability layouts should prioritize current status and trend visibility. They are optimized for dense information, quick scanning, and low-friction drill-downs.

## 2. Layout Patterns

- Summary card strip.
- Chart grid.
- Service health matrix.
- Filter bar.
- Time range selector.

## 3. Behavior

- Keep the most important values near the top.
- Maintain clear separation between live and historical data.
- Favor stable panel sizes to reduce visual shift.
