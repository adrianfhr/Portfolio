# Realtime UI

> **Scope:** Live state indicators and continuously updating surfaces  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Realtime UI should make activity feel current without overwhelming the user. It is used for live logs, metrics, status indicators, and connection state.

## 2. Common Patterns

- Live badge.
- Connection dot.
- Stale data warning.
- Countdown or progress marker.

## 3. Behavior

- Distinguish live, stale, reconnecting, and offline states.
- Keep updates subtle but visible.
- Make fallback states explicit.
