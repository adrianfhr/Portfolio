# Colors

> **Scope:** Global color system  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

The palette should feel technical, restrained, and high-contrast. Dark surfaces anchor the experience, while bright accents are reserved for status, interaction, and key action states.

## 2. Core Palette

| Token | Light | Dark | Use |
|---|---|---|---|
| Primary | Blue | Blue | Primary actions, links, focus states |
| Surface | Off-white | Near-black | Page and panel backgrounds |
| Surface Elevated | White | Slate | Cards, modals, terminal panels |
| Border | Light gray | Slate gray | Dividers and outlines |
| Success | Green | Green | Healthy states and completion |
| Warning | Amber | Amber | Caution and attention |
| Error | Red | Red | Failure and validation errors |
| Info | Blue | Sky blue | Neutral status and highlights |

## 3. Semantic Rules

- Use color to support meaning, not replace it.
- Keep alert colors reserved for genuine conditions.
- Preserve readable contrast for all text/background combinations.
