# Typography

> **Scope:** Global type scale and font usage  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Typography should reinforce clarity and technical credibility. Sans-serif text handles most interface content, while monospace is reserved for code, logs, metrics, and tabular values.

## 2. Font Families

- UI text: clean sans-serif system or project-approved modern sans.
- Terminal and code: monospace family such as JetBrains Mono or Fira Code.
- Numbers and metrics: use tabular numeral styling where available.

## 3. Scale

- Use a compact scale for dashboards and dense tool interfaces.
- Reserve larger display text for headline-level showcase moments.

## 4. Rules

- Favor legibility over decorative styling.
- Keep line lengths comfortable for long-form docs and chat messages.
- Use consistent weight hierarchy rather than too many font sizes.
