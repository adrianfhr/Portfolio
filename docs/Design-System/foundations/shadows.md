# Shadows

> **Scope:** Elevation and glow treatment  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Shadows should define hierarchy without making the UI feel soft or generic. Use subtle elevation for panels and more pronounced treatment only for modals or critical overlays.

## 2. Elevation Levels

| Level | Usage |
|---|---|
| 0 | Flat background surfaces |
| 1 | Cards and small panels |
| 2 | Floating controls and drawers |
| 3 | Modals and overlays |
| 4 | Critical foreground surfaces |

## 3. Style Guidance

- Prefer soft, directional shadows over heavy blur.
- Use glow sparingly for live or active states.
- Keep focus rings distinct from elevation shadows.
