# Interaction Philosophy

> **Scope:** Motion, feedback, and responsiveness principles  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Interaction should feel immediate, truthful, and low-friction. The user should always understand what the interface is doing and whether their action succeeded.

## 2. Principles

- Respond quickly to input.
- Reflect backend state honestly.
- Keep transitions short and meaningful.
- Make recovery paths obvious.

## 3. Accessibility

- Respect reduced-motion preferences.
- Preserve keyboard flows.
- Keep important changes visible without relying on animation.
