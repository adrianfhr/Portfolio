# Visual Direction

> **Scope:** Aesthetic strategy and reference points  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

The visual direction should feel like modern engineering software: dark, crisp, and dense with information, but still polished enough to be portfolio-worthy.

## 2. Influences

- Linear for structure and clarity.
- Vercel for clean presentation.
- Raycast for utility-driven polish.
- Datadog and Grafana for telemetry density.

## 3. Rules

- Dark mode should feel intentional, not defaulted.
- Accents should be used with restraint.
- Surfaces and spacing should make complex data readable.
