# Terminal

> **Scope:** Live logs and console-style surfaces  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

The terminal style is used for live logs, JSON inspection, and any view that benefits from a console aesthetic. It should feel technical and readable at all times.

## 2. Visual Rules

- Dark background.
- Monospace typography.
- Compact line height.
- Distinct coloring for severity and status.

## 3. Behavior

- Auto-scroll should be user-aware.
- Long lines should truncate gracefully.
- Copy and export actions should be obvious.
