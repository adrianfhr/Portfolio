# Cards

> **Scope:** Global card system  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Cards should organize content into readable surfaces with clear hierarchy. They are the primary building block for dashboards, results, and summary views.

## 2. Variants

- Metric card.
- Info card.
- Result card.
- Interactive card.

## 3. Behavior

- Support hover emphasis when interactive.
- Keep card headers and footers visually distinct.
- Avoid overusing shadows inside nested card layouts.
