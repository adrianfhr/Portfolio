# Input Fields

> **Scope:** Form inputs and data entry controls  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Input fields should be consistent, readable, and clearly state their current state. They are used for prompts, filters, forms, and configuration controls.

## 2. Types

- Text input.
- Textarea.
- Slider.
- Select dropdown.
- File upload.
- Search box.

## 3. States

- Default.
- Hover.
- Focus.
- Disabled.
- Error.
- Success.

## 4. Behavior

- Provide clear labels.
- Surface validation inline.
- Keep keyboard interactions predictable.
