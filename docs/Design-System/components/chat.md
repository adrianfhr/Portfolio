# Chat

> **Scope:** Chat and streamed-response surfaces  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Chat components should make conversation, streaming, and citation behavior easy to scan. They should feel like a premium developer tool rather than a generic messaging app.

## 2. Core Pieces

- Message bubbles.
- Input area.
- Typing indicator.
- Citation pills.
- Markdown container.

## 3. Behavior

- User and assistant messages must be visually distinct.
- Streaming updates should not overwhelm accessibility layers.
- Code blocks need copy affordances.
