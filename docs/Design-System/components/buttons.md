# Buttons

> **Scope:** Global button system  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Buttons should be clear, direct, and visually consistent across the product. The default treatment should make the primary action obvious without overpowering the rest of the interface.

## 2. Variants

- Primary: main action.
- Secondary: supporting action.
- Ghost: low-emphasis action.
- Danger: destructive action.

## 3. States

- Default, hover, active, focus, disabled, loading.

## 4. Behavior

- Maintain visible focus styles.
- Keep loading states explicit.
- Use icon-only buttons only when the action is universally recognizable or labeled.
