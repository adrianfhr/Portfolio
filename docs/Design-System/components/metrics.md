# Metrics

> **Scope:** Summary cards and chart-friendly metric surfaces  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Metric components should make numbers feel trustworthy and immediately understandable. They are used heavily in the observability dashboard and anywhere the product needs to show live system state.

## 2. Components

- Stat card.
- Sparkline.
- Gauge.
- Trend badge.

## 3. Behavior

- Use clear labels and units.
- Highlight positive and negative change without ambiguity.
- Keep numeric formatting consistent.
