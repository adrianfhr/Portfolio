# Modals

> **Scope:** Global modal system  
> **Version:** 1.0  
> **Status:** Draft

## 1. Overview

Modals should interrupt only when the task is important and cannot be solved inline. They need to feel stable, focus-safe, and easy to dismiss.

## 2. Types

- Alert.
- Confirm.
- Form.
- Quota or permission modal.

## 3. Behavior

- Trap focus while open.
- Lock background scroll.
- Close via Escape or backdrop when appropriate.
